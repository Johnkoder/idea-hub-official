# IdeaHub Privacy

## Local Data

IdeaHub stores workspace content locally on the user's device.

## Accounts

IdeaHub v1.0.0 does not require a user account.

## Cloud Synchronization

IdeaHub v1.0.0 does not include cloud synchronization.

## Telemetry and Analytics

IdeaHub v1.0.0 does not intentionally include analytics or telemetry services.

## Network Access

IdeaHub is designed to operate offline.

## Backups

Users can export local `.ideahub` project backups. Users are responsible for where those backup files are stored or shared.

## Future Versions

Future versions may change functionality. Privacy documentation should be updated if networked features are added.
